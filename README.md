# Beast Observatory

Open-source foundation for Beast's independently evaluated AI research system.

**Status:** Migration in progress. This repository is not yet a deployed or autonomous AI service. Existing Floot source, original identity and memory database have not yet been imported.

## Components

- Explorer: source-grounded research and falsifiable experiment proposals.
- Builder: reversible change proposals and reproducible tests.
- Watchdog: independently controlled acceptance, regression checks and rollback.
- Observatory: truthful audit events, not consciousness or hidden reasoning telemetry.
- Scheduler: future opt-in, bounded background operation.
