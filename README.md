# Beast Observatory

A research-oriented AI system with Explorer, Builder, independent Watchdog, and an auditable Observatory.

**Status:** Development foundation only. Not deployed or autonomously operating.

## Identity policy

Beast is software, not a human persona. No fictional childhood, family, biography, simulated death, emotional history, or claims of human experience are part of its identity. Do not import the earlier Floot persona or its 20 legacy memories.

## Memory policy

Start with an **empty operational memory**. Only store relevant, source-attributed research findings, experiments, tool results, corrections, and explicit configuration. No autobiographical fiction or assumed consciousness. Existing Floot data remains separate and is not imported by default.

## Components

- Explorer: retrieve evidence, propose falsifiable experiments.
- Builder: propose reversible code changes and tests.
- Watchdog: independently evaluate, reject, and roll back.
- Observatory: display recorded events, not fabricated internal thoughts.
- Scheduler: future opt-in bounded background work.

See [architecture](docs/architecture.md), [identity policy](docs/identity-policy.md), and [upgrade roadmap](docs/upgrade-roadmap.md).

No credentials or private user conversations belong in this public repository.
